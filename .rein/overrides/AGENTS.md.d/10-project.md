## Private context stays private

This repo is public; the owner's other repositories are not. Never
write their names, internal paths, product names, ticket ids, or
employer references into any committed file or commit message —
field-test targets and examples are referred to generically ("a
private Angular workspace"). Same standing as ground rule 1: the
history must stay publishable, and a name leaked once is cached
forever.
