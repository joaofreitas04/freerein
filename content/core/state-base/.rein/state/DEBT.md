# Debt ledger

Known-broken or never-run things, recorded instead of gated — a gate
that is red from birth trains agents to ignore it. Each entry names
the debt, the evidence, and the paydown trigger. Retire entries by
fixing them, never by deleting the line without the fix. A trigger
should be an event or a date the project cannot miss; a dated trigger
that has passed makes the entry active again — recorded debt with no
expiry is how an exception quietly becomes policy.
